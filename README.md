# AI产品思维 · 互动课程网站

在线访问：https://yoyo2027.github.io/product-thinking/

给“生成式人工智能应用基础”和“AI 语言工具与实操”两门课的AI产品思维课：四节互动课，加一个 90 分钟工作坊。像一套双张黑胶：第一张唱片是 A、B 面，第二张唱片是 C、D 面，最后一首是 Bonus Track。故事跟着网易云音乐从 2013 年起走，按一条需求链排：收 → 辨 → 选 → 验 → 做。

- **C 面 · 收需求**（`c-side/`）：需求从哪来，怎么理成一张图。练习有渠道连连看、一天的反馈、需求地图、长尾淘金、下个版本，最后写一池**我的需求池**。
- **A 面 · 看见人**（`a-side/`）：用户说的，不一定是用户要的。三招看见真需求：自己去看、追问细节；问“为什么”，找到动机；用角色、场景、流程分辨真伪需求。练习有评论分拣、访谈侦探、剥洋葱、拆 AA 收款，最后写一张**需求体检卡**。
- **B 面 · 做选择**（`b-side/`）：做产品，就是做选择。用三个圈找切入点，第一版只留一个核心功能，有时要对用户说“不”，想清楚什么能带来口碑。最后写一页**我的产品一页纸**，一键生成写给 AI 的需求说明。
- **D 面 · 验需求**（`d-side/`）：拿什么证明你判断对了。练习有猜北极星、问卷体检、数据侦探、软文挤水分、设计 A/B 测试，最后写一份**我的验证计划**。
- **Bonus Track · 录音棚**（`studio/`）：3–4 人一组的工作坊，六个环节：组队选题、互访、理需求、定方案、做第一版、互评。读取前几课写过的卡片，最后导出**作品卡**和**互评卡**。老师可以打开投屏模式，大屏显示环节和倒计时（空格开始或暂停，→ 下一环节）。

四面各配一集约 6 分钟的视频（`assets/video/`，带中文字幕轨道）。四节课都配 6 道自测题和 8 张术语卡。写下的卡片存在浏览器里（只在本机），后面的课和工作坊会读取前面写过的内容；都可以复制成文字或下载成图片。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 课程首页 |
| `a-side/`、`b-side/` | 第一、二课页面和练习脚本 |
| `c-side/`、`d-side/` | 第三、四课页面和练习脚本 |
| `studio/` | 工作坊页面和脚本 |
| `assets/course.css`、`assets/course.js` | 共用的样式和组件 |
| `assets/img/`、`assets/loop/`、`assets/video/` | 插画、头图循环视频、课程视频和字幕 |

不需要构建，整个文件夹下载后，用浏览器打开 `index.html` 就能离线使用（字体需要联网，连不上时会用系统字体）。
