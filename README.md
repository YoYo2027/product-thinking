# AI产品思维 · 两节课互动网站

在线访问：https://yoyo2027.github.io/product-thinking/

给“生成式人工智能应用基础”和“AI 语言工具与实操”两门课的两节AI产品思维课。两节课是一张唱片的两面，跟着网易云音乐从 2013 年起的故事走：

- **A 面 · 看见人**（`a-side/`）：用户说的，不一定是用户要的。三招看见真需求：自己去看、追问细节；问“为什么”，找到动机；用角色、场景、流程分辨真伪需求。练习有评论分拣、访谈侦探、剥洋葱、拆 AA 收款，最后写一张**需求体检卡**。
- **B 面 · 做选择**（`b-side/`）：做产品，就是做选择。用三个圈找切入点，第一版只留一个核心功能，有时要对用户说“不”，想清楚什么能带来口碑。最后写一页**我的产品一页纸**，一键生成写给 AI 的需求说明。

两课都配 6 道自测题和 8 张术语卡。体检卡和一页纸会存在浏览器里（只在本机），B 面会读取 A 面写的体检卡；都可以复制成文字或下载成图片。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 课程首页 |
| `a-side/` | 第一课页面和练习脚本 |
| `b-side/` | 第二课页面和练习脚本 |
| `assets/course.css`、`assets/course.js` | 两课共用的样式和组件 |
| `assets/img/`、`assets/loop/` | 插画和头图循环视频 |

不需要构建，整个文件夹下载后，用浏览器打开 `index.html` 就能离线使用（字体需要联网，连不上时会用系统字体）。
